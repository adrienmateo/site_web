# Portfolio — Adrien-Matéo Soules

Site statique (HTML/CSS/JS), bilingue FR/EN, prévu pour GitHub Pages.


## Organisation

```
index.html, methode.html, demo.html,   pages du site (à la racine : les adresses ne changent pas)
backlog.html, f1.html, 404.html, ...
css/      styles (style.css, extra.css, hero-night.css)
js/       scripts ; js/content.js contient tous les textes FR/EN
images/   photos, logos, captures, vidéos ; images/hero-night/ pour la scène du robot
docs/     CV en PDF (FR et EN)
CNAME     nom de domaine (GitHub Pages)
```
